# 💈 Barbershop Indigo – Modern Presentation Website

🚀 **Barbershop Indigo** is a stylish and fully responsive presentation website built with **HTML, Tailwind CSS, and JavaScript**. It features a dynamic **pricing list** and **photo gallery**, which can be managed via a **custom CMS admin panel**.

https://barbershopindigo.cz/

---

## 🌟 **Features**
✅ **Dynamic Pricing List** – Clients can add or remove services through a CMS  
✅ **Photo Gallery Management** – Easily add or remove photos via the admin panel  
✅ **Fully Responsive Design** – Optimized for all devices  
✅ **Modern UI/UX** – Built with **Tailwind CSS** for a sleek and professional look  
✅ **Fetch API Integration** – Fetches pricing and gallery data dynamically from the CMS  
✅ **Interactive Navigation Menu** – Mobile-friendly and user-friendly design  

---

## 🛠 **Technologies Used**
- **HTML5** – Semantic markup for better SEO and accessibility  
- **Tailwind CSS** – Utility-first styling for rapid development  
- **JavaScript (ES6+)** – Dynamic functionality and CMS integration  
- **Fetch API** – Retrieves data from the CMS system  
- **CMS Admin Panel** – Allows easy management of the pricing list and gallery
